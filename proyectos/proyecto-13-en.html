Neuromotion VR

Description

EEG-based brain–computer interfaces using motor imagery can decode movement intention without requiring physical movement. Most current implementations use abstract two-dimensional feedback such as cursors and bars, which can reduce immersion and the sense of agency.

Neuromotion VR combines Meta Quest 3 with an OpenBCI Cyton EEG headset so that motor-imagery commands control a human avatar in first- or third-person view. The pipeline includes EEG acquisition, CSP+LDA classification, command transmission and avatar control in Unity. When right- or left-hand motor imagery is detected, the avatar raises the corresponding hand in real time.

Objectives

  • Decode right- and left-hand motor-imagery commands from EEG.
  • Control a human avatar in an immersive VR environment in real time.
  • Strengthen the user’s sense of agency through full-body visual feedback.
  • Explore the system’s potential for neurofeedback and neuromotor rehabilitation.

Technology

🖥️ Hardware

Meta Quest 3 + OpenBCI Cyton EEG headset.

⚙️ Software

Unity + Meta XR SDK.
