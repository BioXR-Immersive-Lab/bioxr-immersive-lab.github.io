Vib-AR — Terapia para el Dolor del Miembro Fantasma

Descripción

En América, cada año 90,000 personas sufrirán dolor del miembro fantasma (DMF), y el 87% de ellas lo padecerá por más de 2 años; sin embargo, apenas el 23% busca ayuda profesional para tratarlo. El proyecto busca crear un prototipo de bajo costo, seguro y de uso amigable que combine terapia visual (realidad aumentada) con terapia vibratoria para aliviar este dolor.

El sistema usa MediaPipe (vía webcam y PC) para mostrarle al paciente una mano virtual superpuesta sobre su muñón. Un sensor de movimiento BNO085 detecta cuando el paciente supera un umbral de movimiento del muñón, y en ese momento se dispara una animación del brazo virtual levantándose, generando la ilusión visual de que el miembro perdido se mueve — un principio similar a la terapia de espejo, que busca aliviar el dolor. Un motor de vibración integrado en una banda de TPU flexible complementa la estimulación.

Objetivos

  • Detectar el movimiento del muñón del paciente mediante el sensor BNO085.
  • Mostrar una mano/brazo virtual superpuesto sobre el muñón usando MediaPipe.
  • Disparar una animación del brazo levantándose al superar un umbral de movimiento detectado.
  • Complementar la terapia visual con estimulación vibratoria mediante un motor controlado por Arduino.
  • Aliviar el dolor del miembro fantasma combinando ambas modalidades (visual + vibratoria).

Tecnología

🖥️ Hardware

Webcam + PC, sensor BNO085, Arduino Nano, motor vibratorio, banda de TPU flexible (diseño propio).

⚙️ Software

MediaPipe + firmware Arduino (control de sensor BNO085 y motor vibratorio).
